# Support

## Where to ask

- **Bug reports and feature requests** — open a GitHub issue (use the
  templates: bug report or feature request).
- **Questions about using appstudy** — open a discussion or an issue labelled
  `question`.
- **Security issues** — see [SECURITY.md](SECURITY.md); do not post exploit
  details publicly.

## Before you ask

1. Check you are on the latest `0.1.x` release.
2. Try the sample site first: `python3 -m appstudy study examples/sample-site --local`
   — if that works and a live site does not, the difference is usually the
   site itself (see [docs/limitations.md](docs/limitations.md)).
3. Include your Python version (`python3 --version`), the exact command you
   ran, and the output.

## Response times

This is a one-maintainer project maintained in spare time. Issues are usually
triaged within a few days; pull requests that follow
[CONTRIBUTING.md](CONTRIBUTING.md) get reviewed first.
